## Hello
There are two options:
- Lazyvim (branch lazy-vim)
- neovim but too random (branch master)🤣


## Prerequested
- [Neovim](https://neovim.io/) installed

## How to Use:

1. Choose the branch
2. Download the zip file
3. Extract the zip file
4. Copy files inside the extracted folder to `~/.config/nvim`
5. run nvim
